PORTFOLIO SAMAR RABEH — HTML / CSS / JAVASCRIPT

PERSONNALISATION
1. Ajoutez votre photo dans ce dossier et nommez-la profile.jpg.
2. Ajoutez votre CV PDF et nommez-le CV_Samar_Rabeh.pdf.
3. Vérifiez les dates, descriptions de stages, compétences et technologies du projet SmartCare PRO avant publication.
4. Vérifiez les coordonnées que vous souhaitez rendre publiques.

OUVRIR EN LOCAL
Décompressez le ZIP, ouvrez le dossier dans VS Code, puis ouvrez index.html dans un navigateur (ou utilisez Live Server).

OBTENIR UN LIEN PUBLIC GRATUIT AVEC GITHUB PAGES
1. Connectez-vous sur https://github.com et créez un dépôt public nommé portfolio-samar-rabeh.
2. Cliquez sur Add file > Upload files et téléversez les fichiers du dossier.
3. Dans le dépôt, ouvrez Settings > Pages.
4. Sous Build and deployment, choisissez Deploy from a branch.
5. Sélectionnez la branche main et le dossier / (root), puis Save.
6. Attendez la publication. GitHub affichera le lien dans Settings > Pages.
Le lien aura cette forme : https://VOTRE-PSEUDO.github.io/portfolio-samar-rabeh/

Le site n'est pas encore publié : il faut effectuer ces étapes dans votre compte GitHub pour obtenir votre URL personnelle.
